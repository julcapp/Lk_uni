# Мастер создания проекта

Первый интерактивный пользовательский прототип Lk_uni для человека без навыков программирования.

## Запуск

Откройте файл `index.html` в браузере.

## Реализованный сценарий

1. Главная страница с кнопкой «Создать мой проект».
2. Ввод названия проекта.
3. Выбор направления деятельности.
4. Создание первого владельца.
5. Имитация автоматического создания рабочего пространства.
6. Экран готового проекта.
7. Первая главная страница проекта.

На данном этапе данные не отправляются в backend и не сохраняются. Прототип предназначен для проверки понятности интерфейса и пользовательского сценария перед подключением API.
