# История изменений

Все существенные изменения Lk_uni фиксируются в этом файле.

Формат основан на Keep a Changelog. Семантическое версионирование применяется после начала публичных релизов.

## [Unreleased]

### Добавлено

- руководство по воспроизводимому запуску и проверке backend;
- единая последовательность развития от подтверждённого baseline к DX, Platform Kernel и Identity;
- явные критерии подтверждённой реализации и версии `v0.1.0-alpha`.

### Изменено

- README синхронизирован с фактическим состоянием кода;
- возможности разделены на реализованные, частично реализованные и запланированные;
- восстановление пароля больше не представлено как завершённая функция;
- `PROJECT_STATUS.md` переведён с конкурирующей стратегии Demo First на единый implementation-first baseline;
- Roadmap исключает параллельное создание второго Auth Core и предусматривает эволюционное выделение Kernel и Identity;
- целевая первая alpha-версия исправлена с `v1.0.0-alpha` на `v0.1.0-alpha`.

### Исправлено

- устранена нерабочая ссылка README на отсутствующий `backend/README.md`;
- устранены противоречия между README, Roadmap и статусом проекта;
- документация больше не приравнивает архитектурные планы и UI-прототипы к готовому runtime.

## [0.1.0] — Foundation Preview

### Добавлено

- Node.js / Express backend;
- PostgreSQL migrations и seed;
- project-aware Auth Core;
- JWT access и refresh tokens;
- session rotation и revoke;
- audit events;
- CI с PostgreSQL 16;
- базовые интеграционные тесты;
- продуктовая документация и правила open source взаимодействия;
- архитектурная схема и три контура доступа.
