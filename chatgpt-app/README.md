# Lk_uni ChatGPT App

Демонстрационное ChatGPT-приложение поверх Lk_uni. Оно предоставляет три read-only MCP-инструмента и интерактивный кабинет:

- `get_my_access_summary` — границы пользовательского доступа;
- `get_my_profile` — собственный профиль и связанные identities;
- `get_security_status` — состояние сессий и рекомендации безопасности.

Первая версия реализует только контур `User App`. Настройки проекта и глобальные политики платформы намеренно не публикуются как MCP-инструменты.

## Локальный запуск

Из корня репозитория:

```bash
npm install
npm run chatgpt:start
```

MCP endpoint: `http://localhost:8787/mcp`.

Для подключения к ChatGPT endpoint должен быть доступен по HTTPS. Используйте Secure MCP Tunnel, ngrok или Cloudflare Tunnel, затем укажите публичный URL с путём `/mcp` в режиме разработчика ChatGPT.

## Ограничения первой версии

- Данные демонстрационные и хранятся в памяти процесса.
- Инструменты только читают данные.
- Project Admin App и Platform Owner Console описаны архитектурно, но не подключены к этому MCP-серверу.
- OpenAI API key не требуется.
- Production-версия должна получать профиль из PostgreSQL после серверной проверки авторизации.
