# Lk_uni

> **Создавайте свой продукт. Управление пользователями возьмёт на себя Lk_uni.**

**Lk_uni — готовая система регистрации, авторизации и личного кабинета для любого проекта. Подключите Lk_uni одной интеграцией и получите современную систему управления пользователями.**

Подключите Lk_uni — и через несколько минут ваш проект получит регистрацию пользователей, авторизацию, управление профилем, личный кабинет, управление сессиями и REST API без необходимости разрабатывать эту инфраструктуру самостоятельно.

## Статус проекта

Lk_uni находится в активной разработке. Текущий технологический стек целевой версии: **Node.js / Express / PostgreSQL / React**.

Уже реализована первая вертикаль PostgreSQL Auth Core: project-aware регистрация и вход, подтверждение identity, JWT access/refresh, ротация refresh-токенов, управление собственными сессиями, аудит и интеграционные тесты.

## Для кого создан Lk_uni

Lk_uni предназначен для разработчиков и команд, создающих:

- SaaS-сервисы;
- CRM и ERP;
- интернет-магазины и маркетплейсы;
- мобильные приложения;
- Telegram Mini Apps и ботов;
- корпоративные порталы;
- программы лояльности;
- AI-сервисы;
- внутренние информационные системы.

## Что получает проект

- регистрацию и вход пользователей;
- email- и phone-based identities;
- внешние провайдеры идентификации;
- подтверждение контактов;
- восстановление доступа;
- JWT access и refresh tokens;
- управление сессиями и устройствами;
- пользовательский профиль;
- личный кабинет;
- управление согласиями;
- журнал событий безопасности;
- REST API;
- будущие SDK и готовый виджет авторизации.

## Главный принцип

Пользователь — единая сущность. Email, телефон, Telegram, MAX, VK ID, SberID и другие каналы являются связанными способами идентификации одного пользователя, а не отдельными аккаунтами.

```text
User
  └── Identities
        ├── email
        ├── phone
        ├── telegram
        ├── max
        ├── vk
        └── sberid
```
