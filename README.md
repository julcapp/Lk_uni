# Регистрация в личном кабинете — типовая форма

Стек: **Node.js / Express / MySQL** (бэкенд) + **React** (форма, `frontend/RegisterForm.jsx`).

## Сценарий регистрации

1. **Телефон.** Пользователь вводит номер → фронт спрашивает подтверждение
   («Всё верно?») → только после «да» бэкенд инициирует звонок через
   **SMSC.ru** (`wait_call.php`, https://smsc.ru/api/http/miscellaneous/waitcall/).
   SMSC в ответе сразу возвращает номер, с которого позвонит, — его последние
   6 цифр становятся кодом подтверждения. Пользователю отвечать на звонок
   не нужно, он просто вводит эти 6 цифр в форму.
2. **Почта.** Разрешён только домен **@yuodomen.ru** — проверка и на фронте,
   и на бэкенде (`ALLOWED_EMAIL_DOMAIN` в `.env`). На почту отправляется
   6-значный код, который нужно ввести для подтверждения.
3. **Готово.** Аккаунт активируется, выдаются JWT access/refresh токены.
4. **Опционально — привязка внешних сервисов**: VK, MAX, Telegram, SberID.
   Реализовано через единый интерфейс `services/oauth/provider.interface.js`
   и реестр `services/oauth/registry.js` — новый провайдер добавляется одним
   файлом, без изменений в контроллере/роутах.

## Структура

```
backend/
  db/schema.sql                     — таблицы MySQL
  config/db.js                      — пул соединений MySQL
  services/callVerification.service.js  — звонок-подтверждение (SMSC)
  services/email.service.js         — код на почту, проверка домена
  services/oauth/
    provider.interface.js           — общий интерфейс провайдера
    registry.js                     — реестр подключённых провайдеров
    vk.provider.js                  — VK OAuth2 (рабочая реализация)
    telegram.provider.js            — Telegram Login Widget (рабочая реализация)
    sberid.provider.js              — Сбер ID OAuth2/OIDC (эндпоинты-заглушки)
    max.provider.js                 — MAX (заглушка, ждёт документацию)
  controllers/auth.controller.js
  routes/auth.routes.js
  server.js
frontend/
  RegisterForm.jsx                  — форма (шаги: телефон → почта → готово)
  RegisterForm.css
```

## Что нужно сделать перед запуском

1. `cd backend && npm install`, скопировать `.env.example` → `.env`,
   заполнить логин/пароль SMSC, SMTP-доступ для домена yuodomen.ru,
   параметры MySQL, секреты JWT.
2. Выполнить `backend/db/schema.sql` на вашей MySQL.
3. Запустить: `npm run dev` (или `npm start`).

## Открытые вопросы — прошу уточнить

Чтобы не додумывать за вас, оставил как есть до вашего ответа:

- **MAX**: нет проверенной документации по OAuth-входу для сторонних
  сайтов — `max.provider.js` сейчас заглушка. Пришлите ссылку на
  документацию/личный кабинет разработчика — заполню по аналогии с VK.
- **Сбер ID**: реализован типовой OAuth2/OIDC flow, но конкретные URL
  авторизации/токена/userinfo помечены `TODO` — они зависят от того,
  к какому контуру подключение оформлено у вас в личном кабинете Сбера.
- **Сессия пользователя**: сделал JWT (access + refresh) как современный
  стандарт — если вам нужны серверные сессии в MySQL вместо JWT, скажите,
  переделаю.
- Антифрод-лимит на дозвон (ошибка 6 от SMSC — «превышен лимит звонков
  на номер за сегодня») сейчас просто пробрасывается пользователю текстом
  ошибки. Если нужен отдельный сценарий (например, fallback на SMS или
  повтор через N часов) — скажите, добавлю.
