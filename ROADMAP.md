# Дорожная карта Lk_uni

Дорожная карта описывает последовательность зрелости платформы. Конкретная работа ведётся через GitHub Issues и Pull Requests.

## Этап 0. Воспроизводимый baseline

Статус: **в работе**

- чистая установка backend;
- запуск PostgreSQL 16;
- применение миграций и seed;
- проверка `/health`;
- выполнение тестов базы данных и Auth Core;
- проверка frontend install/build;
- проверка ChatGPT User App;
- устранение расхождений между кодом и документацией.

Этап завершается только после фиксации фактических результатов проверки.

## Этап 1. Инженерная основа

- единая CLI проекта;
- команды диагностики и проверки качества;
- единый сценарий запуска всех тестов;
- закреплённые версии инструментов;
- единые правила Pull Request и Definition of Done;
- CI для backend, frontend, PostgreSQL и интеграционных тестов.

## Этап 2. Platform Kernel

Kernel выделяется эволюционно из действующего backend, без создания параллельной реализации.

- базовые ошибки и Result;
- идентификаторы;
- время и системные часы;
- доменные и прикладные события;
- диагностические и аудиторские абстракции;
- правила зависимостей модулей.

## Этап 3. Identity Core

- единая модель пользователя;
- связанные identities;
- подтверждение email и телефона;
- provider registry;
- изоляция данных подключённых проектов;
- аудит изменений identity;
- модульные границы и репозитории.

## Этап 4. Authentication Core

- регистрация и вход;
- access/refresh tokens;
- rotation и защита от повторного использования;
- logout и отзыв сессий;
- полный процесс восстановления забытого пароля;
- rate limits и anti-abuse;
- негативные сценарии;
- production provider adapters.

## Этап 5. Authorization и проекты

- роли и разрешения;
- политики проекта;
- организации;
- административное управление одним разрешённым проектом;
- строгая изоляция пользовательского, проектного и платформенного контуров.

## Этап 6. Профиль и личный кабинет

- профиль пользователя;
- контакты;
- настройки;
- согласия;
- активные сессии и устройства;
- подключённые identities;
- экспорт и удаление данных по политикам проекта;
- русский и английский интерфейс с единым переключателем языка.

## Этап 7. OpenAPI и SDK

- OpenAPI как исполняемый контракт;
- проверка обратной совместимости;
- JavaScript/TypeScript SDK;
- React bindings;
- серверные примеры;
- API Explorer.

## Этап 8. Готовые интерфейсы и интеграции

- hosted login;
- регистрация;
- восстановление доступа;
- profile widget;
- Admin Console;
- Telegram, GitHub, Google и платёжные плагины через отдельные адаптеры.

## Этап 9. Первый публичный alpha-релиз

Целевая версия: `v0.1.0-alpha`.

- Docker quick start;
- подтверждённый чистый запуск;
- стабильный базовый API;
- OpenAPI;
- SDK preview;
- демонстрационная интеграция;
- release notes;
- security review.

## Правило завершения этапа

Этап завершён только когда готовы:

1. рабочая реализация;
2. позитивные и негативные автоматические тесты;
3. подтверждённая воспроизводимость;
4. актуальная документация;
5. примеры интеграции, если этап затрагивает публичный API;
6. обновлённый CHANGELOG;
7. успешный CI.
