# Lk_uni Product Requirements Specification

Этот раздел является главным каталогом требований к продукту.

## Документы

- `01_PRODUCT_VISION.md` — назначение и позиционирование.
- `02_FUNCTIONAL_REQUIREMENTS.md` — функциональные требования.
- `03_NON_FUNCTIONAL_REQUIREMENTS.md` — производительность, надёжность и сопровождение.
- `04_SECURITY_REQUIREMENTS.md` — требования безопасности.
- `05_INTEGRATION_REQUIREMENTS.md` — API, SDK, webhooks и способы встраивания.
- `06_UX_REQUIREMENTS.md` — требования к пользовательскому опыту.
- `07_DEVELOPER_REQUIREMENTS.md` — Developer Sandbox и документация интегратора.
- `08_ROADMAP.md` — порядок разработки.

## Текущий приоритет

Сначала реализуется и проверяется `Lk_uni Demo v0.1 / DevHub Demo`. Production Core, SDK и Identity Federation развиваются после архитектурной и UX-ревизии Demo.
