# ADR-0001: Lk_uni как Identity Platform

- **Статус:** принято
- **Дата:** 2026-07-10

## Контекст

Проект начинался как форма регистрации и входа, но должен повторно использоваться в разных сервисах.

## Решение

Развивать Lk_uni как самостоятельную Identity Platform, включающую регистрацию, вход, verification, recovery, sessions, security, notifications, API и Developer Sandbox.

## Последствия

- Бизнес-данные проектов не хранятся в Lk_uni.
- Интеграции используют единое ядро.
- Все функции проектируются с UI, API и документацией.
