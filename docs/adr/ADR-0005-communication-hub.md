# ADR-0005: Communication Hub

- **Статус:** принято
- **Дата:** 2026-07-10

## Контекст

Пользователь должен получать служебные уведомления по подтверждённым каналам, а логика отправки не должна быть зашита в регистрацию или вход.

## Решение

Создать событийный Communication Hub с каналами:

- email;
- MAX;
- Telegram;
- SMS/phone;
- Internal Inbox.

## Политика

- После регистрации отправляется уведомление.
- Первый вход, новое устройство и рисковые события уведомляются.
- Обычные входы не создают лишний поток сообщений.
- Пароли, токены и секреты не отправляются.

## Последствия

Demo v0.1 использует Demo Inbox и mock-каналы. Production подключает реальные provider adapters.
