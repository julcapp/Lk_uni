# ADR-0006: Восстановление доступа

- **Статус:** принято
- **Дата:** 2026-07-10

## Контекст

Отправка постоянного пароля по email или через мессенджеры создаёт неприемлемый риск компрометации.

## Решение

Основной Recovery Flow:

1. пользователь инициирует восстановление;
2. подтверждает личность через verified identity;
3. получает одноразовую защищённую ссылку или challenge;
4. самостоятельно задаёт новый пароль;
5. старые сессии отзываются;
6. отправляется уведомление безопасности.

Временный пароль допускается только как отдельная enterprise-политика с коротким TTL и обязательной сменой при первом входе.

## Последствия

Постоянные пароли не передаются через Communication Hub. Recovery не раскрывает факт существования аккаунта постороннему пользователю.
