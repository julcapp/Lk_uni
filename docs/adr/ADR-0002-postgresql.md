# ADR-0002: PostgreSQL как целевая СУБД

- **Статус:** принято
- **Дата:** 2026-07-10

## Контекст

Текущая реализация использовала MySQL, но платформа требует развитой модели данных, JSONB, надёжных транзакций и удобной миграционной стратегии.

## Решение

Целевая СУБД — PostgreSQL. MySQL считается legacy-направлением.

## Последствия

- Новые схемы и миграции создаются под PostgreSQL.
- Подключение хранится в `DATABASE_URL`.
- Для миграций выбран Knex, для подключения — официальный драйвер `pg`.
- Legacy MySQL удаляется после переноса запросов в Auth Core.
