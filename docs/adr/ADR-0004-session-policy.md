# ADR-0004: Управление сессиями

- **Статус:** принято
- **Дата:** 2026-07-10

## Контекст

Identity Platform должна контролировать не только вход, но и жизненный цикл пользовательской сессии.

## Решение

Включить Session Management в ядро Lk_uni.

Обязательные параметры:

- `idle_timeout`;
- `absolute_timeout`;
- `warning_before_expire`;
- `remember_me` как проектная опция;
- список активных сессий;
- отзыв отдельной или всех сессий.

Типовой idle timeout для личного кабинета — 30 минут.

## Последствия

После истечения сессии пользователь получает понятное сообщение и предложение повторной авторизации. После восстановления доступа старые сессии по умолчанию отзываются.
