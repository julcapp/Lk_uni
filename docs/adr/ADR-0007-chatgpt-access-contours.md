# ADR-0007: Жёсткие контуры доступа ChatGPT App

## Статус

Принято, 2026-07-12.

## Контекст

Lk_uni подключается к ChatGPT через MCP. Без явного разделения инструментов пользовательский помощник мог бы получить чрезмерно широкую поверхность действий, включая проектные или глобальные настройки.

## Решение

Вводятся три независимых контура:

### User App

- работает только с текущим аутентифицированным пользователем;
- видит собственный профиль, identities, сессии и рекомендации безопасности;
- на первом этапе преимущественно read-only;
- безопасные изменения будут добавляться отдельными узкими инструментами с подтверждением.

### Project Admin App

- разворачивается и авторизуется отдельно;
- ограничивается одним разрешённым `project_id`/tenant;
- требует серверной проверки административной роли;
- не имеет доступа к глобальным политикам платформы.

### Platform Owner Console

- отделена от пользовательского ChatGPT App;
- управляет глобальными политиками, провайдерами и архитектурными настройками;
- не публикует концептуальные настройки в пользовательской MCP-поверхности;
- критические операции требуют усиленной аутентификации, подтверждения и аудита.

## Правила реализации

1. Авторизация проверяется backend Lk_uni при каждом вызове инструмента.
2. ChatGPT не определяет права и не получает прямого доступа к PostgreSQL.
3. Один MCP-инструмент выполняет одно узкое действие.
4. Инструменты разных контуров не регистрируются на одном пользовательском endpoint.
5. Все изменения состояния имеют корректные MCP-аннотации и запись в audit log.
6. Операции безопасности требуют повторного подтверждения пользователя, где это применимо.
7. Глобальные изменения не реализуются в первой версии ChatGPT App.

## Последствия

Положительные:

- минимизация ущерба при ошибке или компрометации;
- понятная модель ролей;
- невозможность случайного изменения концепции Lk_uni обычным пользователем;
- независимое развитие пользовательского, административного и владельческого интерфейсов.

Ограничения:

- потребуется отдельная регистрация MCP-инструментов и политики авторизации для каждого контура;
- административные функции появятся позже пользовательского прототипа.
