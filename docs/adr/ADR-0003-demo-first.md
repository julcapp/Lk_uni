# ADR-0003: Demo First

- **Статус:** принято
- **Дата:** 2026-07-10

## Контекст

Архитектура платформы сформирована, но продуктовый и интеграционный сценарии ещё не проверены на цельной демонстрации.

## Решение

Сначала реализовать `Lk_uni Demo v0.1` с единственным tenant DevHub. Production Core, SDK и Federation развивать после UX- и security-ревизии Demo.

## Последствия

- Текущий приоритет — запускаемый Demo Runtime.
- Новые идеи фиксируются, но не расширяют scope Demo v0.1.
- Следующий релиз после Demo Review — `v1.0 Preview`.
