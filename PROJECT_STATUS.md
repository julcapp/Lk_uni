## Текущий приоритет

Не расширять production-функциональность до проверки демонстрации.

```text
Welcome → Экскурсия → DevHub → Регистрация → Verification →
Communication Hub → Кабинет → Login → Recovery → Session → Sandbox
```

## Definition of Done для Demo v0.1

- Demo запускается локально одной понятной командой или launcher-файлом.
- Единственный демонстрационный tenant — DevHub.
- Доступны режимы «Экскурсия» и свободная работа.
- Работают сценарии регистрации, входа и восстановления.
- MAX, Telegram, email и телефон представлены mock-провайдерами.
- Демонстрируются ошибки, таймаут сессии и повторная авторизация.
- Есть Demo Inbox для служебных уведомлений.
- Есть минимальный Developer Sandbox.
- Подготовлены пользовательский и интеграционный мануалы.
