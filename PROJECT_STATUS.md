# Lk_uni — статус проекта

**Текущая стадия:** воспроизводимый baseline  
**Архитектурная стадия:** Identity Platform foundation  
**Следующая контрольная версия:** `v0.1.0-alpha`  
**Текущий стек:** Node.js · Express · PostgreSQL · React

## Официальное направление

Lk_uni развивается как универсальная платформа идентификации, авторизации, пользовательских кабинетов и сервисов пользователей для подключаемых коммерческих проектов.

Существующий PostgreSQL Auth Core является текущей рабочей основой. Новые Kernel и Identity-модули не создаются как параллельная реализация: код выделяется из действующей системы небольшими проверяемыми изменениями без изменения подтверждённого поведения.

## Что считается реализованным

Функция считается реализованной только когда одновременно существуют:

1. рабочий код;
2. позитивные и негативные автоматические тесты;
3. подтверждённый запуск в поддерживаемом окружении;
4. актуальная документация;
5. успешный CI.

Архитектурные документы и интерфейсные прототипы без подтверждённого runtime относятся к статусу «запланировано» или «прототип».

## Критерии версии `v0.1.0-alpha`

- проект запускается по документированной процедуре из чистого клона;
- PostgreSQL 16 поднимается локально и мигрируется автоматически;
- регистрация, подтверждение identity, вход, refresh, logout и управление собственными сессиями покрыты тестами;
- реализован полный процесс восстановления забытого пароля;
- пользовательские экраны поддерживают русский и английский языки;
- OpenAPI соответствует фактическим endpoint;
- CI проверяет backend, frontend, миграции и интеграционные тесты;
- документация не содержит неподтверждённых заявлений о готовности.
