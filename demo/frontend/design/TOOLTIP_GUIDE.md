# Lk_uni UX Tooltip Guide

## Purpose

Tooltips explain fields and actions without overloading the interface.

## Required fields

Registration fields must have contextual hints:

- Name: explain allowed characters.
- Email: explain Latin characters and required @ symbol.
- Phone: explain verification purpose.
- Password: explain security requirements.

## Rules

Tooltip text must be:

- short;
- understandable;
- action oriented.

Example:

"Используйте латинские символы. Пример: example@mail.ru"
