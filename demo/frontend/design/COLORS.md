# Lk_uni Design System — Color Palette

## Purpose

Unified visual language for Lk_uni, DevHub and future integrated projects.

## Base palette

The current approved visual direction is preserved: modern, clean, professional interface with soft contrast and trust-oriented colors.

## Semantic colors

- Primary — main actions and navigation
- Secondary — supporting elements
- Success — completed operations
- Warning — attention states
- Error — validation and security errors
- Background — application surfaces
- Text — primary and secondary text

## Rules

Colors must be used through semantic tokens, not hardcoded values in components.

Example:

primary.button
status.success
message.error

## PAL codes

Final PAL values are stored as design tokens after UI prototype approval.
