# Lk_uni Design System — Buttons v0.1

## Types

- Primary action
- Secondary action
- Danger action
- Link action

## States

Every button supports:

- default
- hover
- pressed
- loading
- disabled

## Rules

Primary action must represent the next recommended user step.

Examples:

- Продолжить
- Войти
- Подтвердить
- Восстановить доступ
