# Lk_uni Design System — Forms v0.1

## Registration fields

### Name

Rules:
- Cyrillic characters
- digits allowed
- hyphen allowed

Hint:
"Введите имя для обращения в сервисе"

### Email

Rules:
- Latin characters
- required @ symbol
- valid domain format

Example:
example@mail.ru

### Password

Requirements:
- minimum 8 characters
- letters
- numbers
- no spaces

## Consent

Demo mode:
- checkbox may be preselected for demonstration

Production mode:
- explicit user action required

## States

- default
- focus
- success
- error
- disabled
