# Lk_uni Design System — Typography v0.1

## Principles

Typography must provide clarity, trust and accessibility.

## Levels

- H1 — page title
- H2 — section title
- Body — main user text
- Caption — hints and metadata
- Error — validation messages

## Rules

- Russian language support required.
- Do not use typography to replace interface structure.
- Tooltip and error text must remain readable on all devices.
