# Lk_uni Design System — Components

## Core components

- Button
- Input Field
- Tooltip
- Card
- Status Badge
- Modal
- Notification Item
- Provider Selector
- Step Indicator

## Principles

All components must support:

- default state;
- hover state;
- loading state;
- success state;
- error state;
- disabled state.

Components are shared between Lk_uni and connected products.
