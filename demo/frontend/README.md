# Lk_uni Demo Frontend v0.1

## Назначение

Frontend демонстрационного приложения Lk_uni.

Цель: показать полный пользовательский путь Identity Platform.

## Основные экраны

1. Welcome / Экскурсия
2. Registration
3. Verification
4. Login
5. Identity Cabinet
6. Security
7. Developer Sandbox

## Принцип

Frontend является представлением Lk_uni Core и не содержит бизнес-логики проектов.
