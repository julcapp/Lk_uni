# Lk_uni Demo v0.1 — User Guide

## Назначение

Демонстрационная среда Lk_uni показывает полный цикл управления цифровой идентичностью:

1. Регистрация пользователя.
2. Подтверждение личности.
3. Создание сессии.
4. Личный кабинет.
5. Управление безопасностью.
6. Восстановление доступа.
7. Developer Sandbox.

## Режим Экскурсия

Пользователь проходит подготовленный сценарий:

Welcome → Registration → Verification → Cabinet → Security → Sandbox

## Demo режимы

- Email Demo Provider
- MAX Demo Provider
- Telegram Demo Provider
- Internal Inbox

## Цель демонстрации

Показать разработчикам и заказчикам возможности Lk_uni как универсального Identity-модуля.
